About This Project

Problem statement: AI-based loan decision systems can improve efficiency, but they can also introduce bias, proxy discrimination, lack of transparency, and other ethical risks. FairLoan provides an educational framework for evaluating these risks.

Objectives
  • Analyze ethical risks in AI loan approval.
  • Detect dataset bias.
  • Assess deepfake-related vulnerabilities.
  • Investigate cost-as-a-proxy resource bias.
  • Evaluate fairness and explainability.
  • Operationalize responsible AI principles via impact assessment.
Expected Outcomes
  • Identify dataset disparities.
  • Measure group-level fairness.
  • Identify possible proxy features.
  • Explain model predictions.
  • Assess deepfake-related risks.
  • Generate an overall ethical assessment.
This is an educational/academic simulation. FairLoan is not a real banking or credit-scoring product and must never be used to make actual financial decisions.
